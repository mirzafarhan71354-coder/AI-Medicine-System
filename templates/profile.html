Browser notifications

Allow notifications in your browser to receive reminders while this device is available. Browser notifications and service workers require HTTPS (localhost is allowed for development). For reminders when the dashboard is closed, the site also needs server-configured Web Push keys.

{% if push_configured %}Web Push is configured on the server. Allow notifications on this device to subscribe. {% else %}Closed-browser push is not configured. The dashboard can show browser alerts while it remains open.{% endif %}

SMS requirements

SMS is sent only when you opt in and Twilio accepts the request. A queued request is not proof of carrier delivery; provider credentials and paid/verified messaging service may be required.

For local development, start py reminder_worker.py in a separate terminal. Set the same three Twilio environment variables in both the Flask app terminal and the worker terminal; restarting only the web app does not start the worker.

Installation

On supported browsers, use the browser menu's “Install app” or “Add to Home Screen” command. Push support differs by browser and operating system.
